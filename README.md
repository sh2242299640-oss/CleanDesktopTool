# 隐藏图标（CleanDesktopTool）
英文名称：CleanDesktopTool

维护者：Sui碎梦
联系方式：QQ 2242299640

Windows 桌面图标与任务栏隐藏工具。基于 .NET Framework 4.8 和 Windows Forms。

## 功能

- 一键隐藏桌面所有图标
- 自动启用"在桌面模式下自动隐藏任务栏"
- 常驻系统托盘，右键图标即可操作：
  - **停止运行脚本**：恢复正常桌面并退出
  - **重启脚本**：刷新设置并重启进程
  - 也可下载后，看功能介绍界面

## 使用

1. 前往 [Releases](../../releases) 页面下载程序构建包/安装包（有问题欢迎进Q群756925381反馈）
2. 运行安装程序，可选择安装位置
3. 安装完成页勾选"运行脚本"，点击完成
4. 桌面即刻进入极简模式，右下角托盘出现图标
5. 如果遇到杀毒软件报错为正常情况，开发者争取在一个月内解决签名问题。本软件绝对不联网，不可能做任何危害个人电脑行为！！！

## 构建

使用 Visual Studio 2022 或更新版本打开解决方案，并使用 .NET Framework 4.8 开发者包构建 `隐藏图标v0.1/隐藏图标v0.7.csproj`。
